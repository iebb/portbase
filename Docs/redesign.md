# Portbase workspace redesign

The iPhone, iPad, and Mac apps share one design system and a set of new workspace features. All database execution still goes through `DatabaseService` with the existing execution policies; none of the new surfaces runs SQL implicitly.

## Design system

`PortSQL/Views/DesignSystem.swift` defines the visual tokens and components used across all platforms:

- **Palette**: a deep navy and slate dark appearance with cool light neutrals, in the style of host managers such as Termius, using adaptive canvas, surface, sunken, and stroke colors with a single flat accent. Cards are flat with a hairline border; there are no decorative glows or shadows. `PortSQLPalette` reads these tokens, so existing screens adopt them automatically.
- **App icon**: the yellow duck on a plain white background (`PortSQL/AppIcon.icon`, shared by iOS and macOS).
- **Accent and appearance**: seven accents (Jade, the default, plus Indigo, Ocean, Emerald, Sunset, Rose, and Graphite), whose dark variants keep white button labels readable, and System/Light/Dark appearance, stored in `UserDefaults` (`Portbase.accent`, `Portbase.appearance`) and applied with `.portbaseTheme()`.
- **Layout tokens**: views take every padding, gap, radius, and size from shared tokens instead of literal numbers.
  - `Spacing` is a 4-point scale (`xxxs` 2, `xxs` 4, `xs` 6, `s` 8, `m` 12, `l` 16, `xl` 20, `xxl` 24, `xxxl` 32) with semantic aliases (`card`, `page`, `rowHorizontal`, `rowVertical`, `chipHorizontal`, `chipVertical`).
  - `Radius` (`xs`, `s`, `chip`, `button`, `control`, `card`, `hero`) keeps corners tight: buttons and controls are 6 pt on the Mac and 8 pt on iOS, cards 10 and 12. `portbaseTheme()` applies `buttonBorderShape(.roundedRectangle(radius: Radius.button))`, so system bordered buttons are squared-off rectangles rather than capsules, and chips, tabs, and badges use small rounded rectangles too.
  - `Sizes` holds control, tool, bar, toolbar, tab-strip, status-bar, row, avatar, icon-tile, symbol-column, dot, gutter, and readable-width values, with 44-point touch targets on iOS.
- **Typography**: the interface is set in Inter and code, values, and the result grids in Source Code Pro. Both are SIL Open Font License fonts bundled unmodified in `PortSQL/Fonts` with `OFL.txt` (Termius itself uses the commercial CircularXX, which can't be bundled). `PortbaseFonts` registers them for the process and supplies SwiftUI, UIKit, and AppKit fonts; navigation bars and segmented controls pick them up through UIKit appearance. Semantic `Font` roles (`displayTitle`, `pageTitle`, `sectionTitle`, `cardTitle`, `bodyText`, `rowTitle`, `rowDetail`, `footnoteText`, `captionText`, `captionStrong`, `microText`, `badgeText`, `codeText`, `codeDetail`, `codeCaption`, `metricValue`) take their sizes from `TypeSize` (Mac 26/20/15/13/12/11/10; iOS 30/22/18/16/15/14/13/12/11, scaled with Dynamic Type), and `portbaseTheme()` makes `bodyText` the default for text without a role.
- **Shared chrome**: `portbaseBar(_:)` for toolbars, status lines, and filter rows; `portbaseSegmentTrack()` and `portbaseSelectedSegment(_:)` for the Mac destination switcher and console tabs; `portbaseFieldChrome()` for search fields; `PortbaseRowDivider` for dividers inset to row text; and `PortbaseSectionHeading`, which keeps a fixed height so headings in neighbouring columns stay aligned.
- **Components**: `PanelCard`, `PortbaseChip`, `PortbaseMetricTile`, `PortbaseEmptyState`, `PortbaseSectionHeading`, `BookmarkAvatar` (engine gradients), `ConnectionSecurityChips`, and `toolIconChrome()` for 44-point tool buttons. Liquid Glass is used on iOS/macOS 26 and later, with a material fallback.
- **Editor themes**: `EditorTheme.swift` provides Portbase, Midnight, Paper, Solarized, and Ember syntax palettes (`Portbase.editorTheme`). The UIKit and AppKit editors both use them, including the line-number gutter and caret.

## Features

| Feature | Where | Behavior |
| --- | --- | --- |
| Home | iOS Home tab; Mac Home destination (⌘0) | Current connection with database switcher, four quick actions, recent queries, 14-day activity (runs, success rate, median time), connections, and saved queries. Loading a recent or saved query never runs it. |
| Connections hub | iOS/iPadOS Servers tab; Mac sidebar → Connections (⌘K → Servers) | Modeled on host managers such as Termius: one bar searches connections or, when a connection string is pasted, offers Import, which opens an unsaved, prefilled connection form under the same explicit TLS rules as the editor. Environment groups filter the grid; connection cards show engine and user, environment, read-only and unencrypted markers, and an actions menu (Open Console, Edit, Duplicate, Delete). On the Mac and in regular-width iPad layouts, an inspector shows the active connection's details, security chips, recent queries, and actions. Double-clicking a card on the Mac opens its console. |
| Command palette | ⌘K on all platforms; Home search button; Mac toolbar | Fuzzy search across actions, destinations, connections, databases, tables, saved queries, and history. Keyboard navigation with ↑/↓, Return, and Esc. |
| Result insights | Results → Insights (SQL tables and MongoDB) | Per-column type, NULL ratio, distinct count, empty-text count, min/median/mean/max, histograms, temporal ranges, and most frequent values. Computed off the main thread from loaded rows only; no extra queries. SQL `NULL`, empty text, the literal string `NULL`, and binary bytes stay distinct. |
| SQL templates | Console tool row; Mac editor toolbar | Select, group-and-count, join, CTE, running total, and (for writable profiles) insert/update/delete/create-index templates. Identifiers are engine-quoted, write templates use named parameters, and inserting a template never executes it. |
| New SQLite database | Home empty state, command palette (all platforms); Mac sidebar | Creates an empty local SQLite file and a connection to it, then opens the console. The Mac-only sample database was removed. |
| Run status | Results chips; Mac editor status bar | Outcome and duration of the last console execution, plus row/column/truncation chips. |
| Settings | iOS Settings sheet; Mac Settings window (General, Appearance, Editor) | Appearance, accent, editor theme, iCloud status and Sync Now, library storage, version, and supported engines. |
| Engine picker | Connection editor | Brand-colored engine tiles replace the menu picker; port, authentication, and icon defaults still follow the selected engine. |
| Query Library | Console library button; Home → Query Library | History rows show outcome, duration, and connection with one-tap outcome filters; saved queries show engine and database. Loading an entry never runs it. |
| Connection strings | Connection editor (first section); ⌘K → Import Connection String; Mac sidebar + menu | Imports PostgreSQL, MySQL, MariaDB (including `jdbc:`), MongoDB (`mongodb://`, `mongodb+srv://`), Redis (`redis://`, `rediss://`), ClickHouse, and Elasticsearch URLs: host, port, percent-decoded credentials, database, and TLS requirements. A string that asks for no TLS or for a fallback never changes the transport mode; a notice explains how to choose it explicitly. Ignored options are listed by name only. |
| Connection errors | Mac top bar and sidebar; Home; console and Explorer on iPhone and iPad | Driver errors are expanded (PostgreSQL connection errors and errors such as NIOSSL's are no longer "The operation couldn’t be completed") and classified as untrusted, mismatched, or expired certificates, TLS unavailable or failed, sign-in failure, unreachable server, or timeout, each with guidance, bounded raw details, Copy Details, Reconnect, and Edit Connection. The Mac uses a single-row banner and a one-line sidebar entry so long errors never change the layout. |
| Environments | Connection editor → Environment | Label a connection Development, Testing, Staging, or Production. Its color appears as a stripe and badge above the console and Explorer, in the Mac top bar and sidebar, on Home, and in the server list. Older data decodes as unlabeled, and an unknown label from a newer version never drops the connection. |
| Copy As | Results → Copy menu; grid context menus (iOS and Mac) | Copy the selection, or every loaded row, as CSV, tab-separated text, JSON, Markdown, or SQL INSERT statements. NULL, empty text, numbers, booleans, JSON, and bytes stay distinct; SQL literals follow each engine's quoting and binary syntax and are never executed by Portbase. |
| MongoDB documents | MongoDB results → Documents | Each document is a card headed by its decoded `_id`, with Copy JSON and Open actions. |
| Test Connection | Connection editor | Checks unsaved settings with read-only requests (listing databases, or `PING` for Redis) and reports the time taken, or the explained connection issue. Nothing is saved. |
| Column types | Result grid headers | Each column shows its database type under (iOS) or beside (Mac) its name. |
| Pinned tables | Explorer sidebar (swipe or context menu); Mac sidebar context menu | Pinned tables stay at the top of the list for that connection and database on this device, and are cleared when the connection is deleted. |
| Visual EXPLAIN | Explain → Results → Plan (selected automatically) | PostgreSQL and ClickHouse text plans, SQLite query plans, and MySQL/MariaDB EXPLAIN rows become an indented tree with costs, relative cost bars, row estimates, details, and warnings for full scans, sorts without an index, and temporary tables. |
| Duplicate Row | Row context menu for editable Explorer tables | Opens the insert editor pre-filled from the row; primary-key and unique columns start empty, NULL stays NULL, and binary values are left out. Saving uses the normal reviewed, parameter-bound insert. |
| Row Details | Mac results bar → Row Details | Lists the selected row's fields vertically with types, NULL and empty-text styling, and per-field copy. |
| Keyboard and haptics | iPad hardware keyboard: ⌘1–⌘5 tabs, ⌘K search, ⌘, settings; Mac: ⌘0 Home, ⌘1–⌘4 destinations | iPhone and iPad give success or error haptics when a console run finishes. |

The console tab strip, Explorer sidebar (row-count badges) and table header chips, Charts grid, and status banners were restyled with the shared components.

## Tests

`PortSQLTests/ConnectionImportAndIssueTests.swift` covers connection-string parsing (credentials, IPv6, JDBC, Redis databases, HTTP engines, and the rule that imports never enable plaintext) and error classification. `PortSQLTests/WorkspaceInsightsAndPaletteTests.swift` covers insight statistics (NULL versus empty text, binary values, temporal ranges, constant histograms), activity aggregation, template quoting and UTF-16 insertion, palette ranking, and preference fallbacks.
