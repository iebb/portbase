# Dev Chart Datasets

The Railway development database now includes deterministic chart-friendly datasets for App Review, screenshots, and QA:

- `chart_doc_sales_daily`
- `chart_doc_marketing_attribution`
- `chart_doc_service_latency`
- `chart_doc_support_satisfaction`
- `chart_doc_shipments`

These tables are designed to cover:

- category bar charts
- date-driven area charts
- pie and donut shares
- line trends
- point/scatter plots
- rule charts
- multi-metric bar charts

The saved chart presets in the simulator are backed by these datasets and can be executed directly from the `Charts` tab.
