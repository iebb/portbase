PortSQL 是一款原生 iPhone SQL 客戶端，支援 MySQL 和 PostgreSQL，適合在外出時快速完成真實資料庫工作。

你可以使用 PortSQL：

- 連接 MySQL 和 PostgreSQL，並透過 iCloud 同步已儲存的伺服器設定。
- 使用語法高亮、自動完成、格式化和 explain 支援執行 SQL。
- 以行動介面瀏覽資料庫、schema、資料表和欄位。
- 透過分頁、欄位排序和資料列詳情檢查查詢結果。
- 以 schema 感知驗證新增和編輯資料列，支援文字、數字、日期、日期時間、UUID 和 JSON。
- 從 SQL 結果建立長條圖、折線圖、面積圖、散點圖、圓餅圖和環圈圖。
- 儲存圖表設定，稍後從 Charts 分頁重新開啟。

PortSQL 適合開發者、維運人員、分析師、創業團隊和客服支援人員，在 iPhone 上完成真正實用的資料庫操作。

常見用途：

- 離開電腦時快速查看正式環境資料
- 針對客服問題檢查即時資料列
- 從 SQL 查詢檢視業務指標
- 在移動中確認 schema 變更和資料表結構
- 不打開筆電也能進行精準資料更新

PortSQL 面向真實資料庫連線而設計。查詢、schema 瀏覽、資料列編輯和圖表視圖都服務於實際 MySQL 和 PostgreSQL 工作流程。
