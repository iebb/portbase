PortSQL é um cliente SQL nativo para iPhone com suporte a MySQL e PostgreSQL, criado para consultas rápidas em produção e trabalho prático com bancos de dados no celular.

Com o PortSQL, você pode:

- Conectar-se a MySQL e PostgreSQL com perfis de servidor salvos e sincronizados pelo iCloud.
- Executar SQL real com destaque de sintaxe, autocompletar, formatação e suporte a explain.
- Navegar por bancos, schemas, tabelas e colunas em uma interface compacta para iPhone.
- Inspecionar resultados com paginação, ordenação de colunas e detalhes de linhas.
- Inserir e editar linhas com validação baseada no schema para texto, números, datas, timestamps, UUID e JSON.
- Criar gráficos de barras, linhas, áreas, pontos, pizza e rosca a partir de resultados SQL.
- Salvar configurações de gráficos e reabri-las depois na aba Charts.

PortSQL foi feito para desenvolvedores, times de operação, analistas, fundadores e equipes de suporte que precisam de um cliente de banco de dados real no iPhone.

Usos comuns:

- Conferir dados de produção longe da mesa
- Investigar chamados de suporte usando linhas reais
- Revisar métricas de negócio a partir de SQL
- Validar mudanças de schema e estruturas de tabelas em movimento
- Fazer atualizações pontuais sem abrir um notebook

PortSQL trabalha com conexões reais de banco de dados. Consultas, exploração de schema, edição de linhas e gráficos foram criados para fluxos MySQL e PostgreSQL práticos.
