PortSQL은 MySQL과 PostgreSQL을 위한 네이티브 iPhone SQL 클라이언트입니다. 이동 중에도 운영 데이터 확인과 실무형 데이터베이스 작업을 빠르게 처리할 수 있습니다.

PortSQL로 할 수 있는 일:

- MySQL 및 PostgreSQL 서버에 연결하고 저장된 서버 프로필을 iCloud로 동기화합니다.
- 구문 강조, 자동 완성, 서식 지정, explain 지원으로 실제 SQL을 실행합니다.
- 모바일에 맞춘 탐색기에서 데이터베이스, 스키마, 테이블, 열을 살펴봅니다.
- 페이지 처리, 열 정렬, 행 상세 보기로 쿼리 결과를 검사합니다.
- 텍스트, 숫자, 날짜, 날짜시간, UUID, JSON에 대한 스키마 기반 검증으로 행을 추가하고 편집합니다.
- SQL 결과에서 막대, 선, 영역, 점, 파이, 도넛 차트를 만듭니다.
- 차트 프리셋을 저장하고 Charts 탭에서 다시 엽니다.

PortSQL은 데스크톱 UI를 작은 화면에 억지로 넣은 앱이 아니라, 개발자, 운영자, 분석가, 창업팀, 지원팀이 iPhone에서 바로 사용할 수 있는 데이터베이스 클라이언트입니다.

일반적인 사용 사례:

- 자리 밖에서 운영 데이터 확인
- 고객 지원 이슈를 실제 행 데이터로 조사
- SQL 쿼리로 비즈니스 지표 검토
- 이동 중 스키마 변경과 테이블 구조 확인
- 노트북 없이 필요한 행만 업데이트

PortSQL은 실시간 데이터베이스 연결을 전제로 합니다. 쿼리, 스키마 탐색, 행 편집, 차트 보기는 실제 MySQL 및 PostgreSQL 워크플로에 맞춰져 있습니다.
