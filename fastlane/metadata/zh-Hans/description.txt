PortSQL 是一款原生 iPhone SQL 客户端，支持 MySQL 和 PostgreSQL，适合随时随地处理真实数据库任务。

使用 PortSQL，你可以：

- 连接 MySQL 与 PostgreSQL 服务器，并通过 iCloud 同步已保存的服务器配置。
- 运行真实 SQL，获得语法高亮、自动补全、格式化和 explain 支持。
- 浏览在线数据库、schema、数据表和字段，界面针对手机屏幕优化。
- 查看查询结果，支持分页、列排序和单行详情。
- 新增和编辑数据行，并根据字段类型进行校验，支持文本、数字、日期、日期时间、UUID 和 JSON。
- 将 SQL 查询结果生成柱状图、折线图、面积图、散点图、饼图和圆环图。
- 保存图表配置，之后可在 Charts 页面重新打开。

PortSQL 面向开发者、运维、分析师、创业团队和客服支持人员，帮助你在 iPhone 上完成真正可用的数据库操作，而不是勉强使用桌面端界面。

典型场景：

- 离开电脑时快速检查生产数据
- 针对真实用户数据排查客服问题
- 直接从 SQL 查询查看业务指标
- 在移动中确认 schema 变更和表结构
- 不用打开笔记本也能完成精确数据更新

PortSQL 连接真实数据库工作。查询、schema 浏览、数据编辑和图表查看都面向真实的 MySQL 与 PostgreSQL 使用场景。
