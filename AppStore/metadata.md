## en-US

### App Name
PortSQL

### Subtitle
SQL Client for MySQL & Postgres

### Promotional Text
Run SQL, browse live tables, edit rows, and chart query results from a native iPhone database client for MySQL and PostgreSQL.

### Description
PortSQL is a native iPhone SQL client for MySQL and PostgreSQL, built for fast production lookups and practical mobile database work.

What you can do with PortSQL:

- Connect to MySQL and PostgreSQL with saved server profiles synced through iCloud.
- Run real SQL with syntax highlighting, autocomplete, formatting, and explain support.
- Browse live databases, schemas, tables, and columns from a compact mobile explorer.
- Inspect query results with paging, sortable columns, and row detail views.
- Insert and edit rows with schema-aware validation for text, numbers, dates, datetimes, UUIDs, and JSON.
- Build charts from SQL results with bar, line, area, point, pie, and donut visualizations.
- Save chart presets and reopen them later from the Charts tab.

PortSQL is designed for developers, operators, analysts, founders, and support teams who need a real database client on iPhone instead of a desktop UI squeezed onto a small screen.

Common uses:

- Check production data away from your desk
- Investigate customer support issues against live rows
- Review business metrics from SQL queries
- Validate schema changes and table structures on the move
- Make targeted row updates without opening a laptop

PortSQL works with live database connections. Queries, schema browsing, row edits, and chart views are built for real MySQL and PostgreSQL workflows.

## ja

### App Name
PortSQL

### Subtitle
MySQL/Postgres対応のiPhone SQLクライアント

### Promotional Text
iPhoneでSQL実行、テーブル閲覧、行編集、クエリ結果のグラフ化まで行える、MySQLとPostgreSQL向けのネイティブDBクライアントです。

### Description
PortSQLは、MySQLとPostgreSQLに対応したネイティブiPhone SQLクライアントです。外出先でも本番データの確認や実務的なデータベース操作を素早く行えます。

PortSQLでできること:

- MySQLとPostgreSQLサーバーに接続し、保存した接続先をiCloudで同期
- 構文ハイライト、自動補完、整形、explain対応でSQLを実行
- データベース、スキーマ、テーブル、カラムをiPhone向けUIで閲覧
- ページング、列ソート、行詳細表示付きでクエリ結果を確認
- テキスト、数値、日付、日時、UUID、JSONに対応した検証付きで行を追加・編集
- SQL結果から棒グラフ、折れ線グラフ、面グラフ、散布図、円グラフ、ドーナツグラフを作成
- グラフ設定を保存し、Chartsタブから再利用

PortSQLは、開発者、運用担当、アナリスト、創業チーム、サポート担当など、iPhoneで実用的なデータベースクライアントを必要とする人向けに設計されています。

主な利用シーン:

- デスクを離れている間に本番データを素早く確認
- 顧客サポートの調査で実データを確認
- SQLクエリからKPIや業務指標をその場で確認
- スキーマ変更やテーブル構造を移動中に確認
- ノートPCを開かずに限定的な行更新を実行

PortSQLは実際のデータベース接続を前提にしています。クエリ実行、スキーマ閲覧、行編集、グラフ表示のすべてが、MySQLとPostgreSQLの実務利用向けです。
