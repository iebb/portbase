## Description
PortSQL is a native iPhone SQL client for MySQL and PostgreSQL, built for fast production browsing and comfortable mobile workflows.

What you can do with PortSQL:

- Connect to MySQL and PostgreSQL servers with saved server profiles synced through iCloud.
- Browse databases and tables with a compact Explorer optimized for iPhone screens.
- Run custom SQL with syntax highlighting, contextual autocomplete, formatting, and explain support.
- Inspect live query results with paging, sortable columns, compact result grids, and row detail views.
- Insert and edit table rows with schema-aware validation for numeric, date, datetime, UUID, JSON, and text fields.
- Inspect table schemas directly in the app and manage columns by adding, editing, or deleting them.
- Save chart configurations from query results and reopen them later from the Charts tab.
- Visualize live SQL data with bar, line, area, point, rule, pie, and donut charts.
- Store chart presets as synced YAML documents backed by iCloud and local cache.

PortSQL is designed for developers, operators, analysts, founders, and support teams who need a real SQL tool on iPhone instead of a desktop UI squeezed onto a small screen.

Ideal use cases:

- Check production rows quickly while away from your desk
- Investigate support cases against live customer data
- Review chartable business metrics directly from SQL queries
- Validate schema changes and table structures on the move
- Make targeted row updates without opening a laptop

PortSQL does not use placeholder datasets in normal operation. Queries, schemas, edits, and charts all work against real database results.
