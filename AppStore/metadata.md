### Promotional Text

### Description
PortSQL is a native iPhone database manager and SQL client for MySQL and PostgreSQL, built for fast production lookups and practical mobile database work.

What you can do with PortSQL:

- Connect to MySQL and PostgreSQL with saved server profiles synced through iCloud.
- Run real SQL with syntax highlighting, autocomplete, formatting, and explain support.
- Browse live databases, schemas, tables, and columns from a compact mobile explorer.
- Inspect query results with paging, sortable columns, and row detail views.

Common uses:

- Check production data away from your desk
- Investigate customer support issues against live rows
- Review business metrics from SQL queries
- Validate schema changes and table structures on the move
- Make targeted row updates without opening a laptop

PortSQL works with live database connections. Queries, schema browsing, row edits, and chart views are built for real MySQL and PostgreSQL workflows.
